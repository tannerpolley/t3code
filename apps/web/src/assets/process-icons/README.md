# Brand icons

SVGs from the Simple Icons npm package, version 14.15.0
(https://www.npmjs.com/package/simple-icons/v/14.15.0), licensed CC0-1.0
(public domain): https://creativecommons.org/publicdomain/zero/1.0/.

Downloaded with `npm pack simple-icons@14.15.0` and extracted as data;
no package code or install scripts were run. Only mapped SVGs are retained.
Each SVG has its brand hex from `_data/simple-icons.json` added as `fill`.
Dark brands use the light variant #DEDDDA for dark Adwaita visibility:
openai (#412991), anthropic (#191919), bun (#000000), openjdk (#000000), llvm (#262D3A), rust (#000000), tailscale (#242424), steam (#000000).

PipeWire and systemd have no SVG in this version, so retain Type fallbacks.
